## API summary

| Component | Purpose | Main methods and functions |
| --- | --- | --- |
| `Syllable` | Represent and analyze a bird-song syllable. | Waveform analysis, filtering, plotting, and feature extraction |
| `Synthetic` | Generate synthetic syllables from model parameters. | Synthesis, parameter handling, and visualization |
| `Song` | Work with collections of syllables as complete songs. | Song construction, segmentation, analysis, and plotting |
| `Model` and `Solver` | Define vocalization models and optimize their parameters. | Model evaluation, fitting, and parameter optimization |
| Data utilities | Download and query audio recordings. | `download_audios`, `query_audios`, and `ProjDirs` |
| Numerical utilities | Provide signal-processing and mathematical helpers. | Filtering, Runge-Kutta integration, Gaussian, sinusoidal, and exponential functions |
